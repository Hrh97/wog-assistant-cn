# 山猪 WoG 助手

《War of Genesis: Idle Loot》的中文本地助手 —— 加点、训练、装备、刷图、伤害、进度、宝玉、仓库、日常自动化，全在一个页面里，直连本机游戏读数据，不经过外网。

> **来源与声明**
> 界面与功能结构来自社区 wiki 的 [Companion 工具页](https://warofgenesis-idleloot.wiki/zh-cn/tools/companion/)（作者已**停止对新版游戏适配**）。本项目在原页面基础上接手继续适配新版，并补了自动化能力。**非官方项目，与游戏开发商、发行商无关。**
> 图鉴数值来自社区整理，个别条目可能和游戏内显示有出入，**以游戏内为准**。

## 三种用法

### 方式一：下载 exe（推荐，给不想装 Python 的人）

到 [Releases](../../releases) 下最新的 `WoG-Assistant.exe`，双击即可 —— 会起本地服务并自动打开浏览器。关掉黑窗口 = 停止服务。

首次运行 Windows 可能弹「已保护你的电脑」，点**更多信息 → 仍要运行**（exe 是用 PyInstaller 打包的，没有代码签名）。

### 方式二：源码跑

```bash
python start.py
```

只依赖 Python 标准库（3.9+），不用装任何包。

### 方式三：在线版（什么都不装）

**<https://wog-assistant.app.workbuddy.host/?sharecode=3BEFAVKQUD>**

在别的电脑 / 手机上查图鉴、算伤害、看排行榜够用了。要真正写进游戏（合成、自动入库、日常自动化）
还得在装了游戏的那台机器上用方式一或方式二 —— 在线版只能连到**访问者自己**本机的游戏。

前两种方式固定用 `127.0.0.1:8791`，重复双击不会开第二个服务，只会把已有页面再打开一次。

> 端口写死是故意的：页面设置存在 `localStorage`，而浏览器按「协议+主机+端口」隔离，端口一变设置就"丢"了。

## 连游戏之前

1. **先启动游戏**《War of Genesis: Idle Loot》，再打开助手
2. 游戏默认不开 `10998`（Puerts Inspector）端口，助手会检测并弹窗，点一次 **「⚡ 注入补丁」** 就好
3. 注入是**改进程内存里的端口号**（把 `-1` 改成 `10998`）：不写游戏文件、不改存档、关掉游戏自动恢复
4. 需要管理员权限时，以管理员身份运行

没有注入也能用：图鉴查询、伤害计算、加点规划、方案保存全部离线可用，只是读不到实时数据、写不进游戏。

## 内核自动化工具（不挂网页也能跑）

网页里的自动化全部是浏览器 `setInterval` —— 关掉页面 / 浏览器回收标签页，定时器就没了。如果你只想要稳定的**内核级合成与技能点加点**、不想一直挂着一个网页，用仓库里的 [`wog_kernel_tools.py`](KERNEL_TOOLS.md)：

```bash
python wog_kernel_tools.py check                 # 只读体检：连通性 / SP / 战场累计
python wog_kernel_tools.py fuse --dry           # 按 GroupID 分组合成，只报告不写
python wog_kernel_tools.py fuse --budget 8      # 真提交，最多 8 组
python wog_kernel_tools.py skill --dry --budget 40   # 技能树 SP 加点计划
python wog_kernel_tools.py skill --once --budget 6    # 真加 6 点，渐进
```

跨平台、零依赖、只用 Python 标准库，直连本机 `ws://127.0.0.1:10998`（同样要先开端口）。它绕开两个实测的游戏内核坑：① 内置自动融合 section 把 T1 材料排除导致低阶装备/宝玉堆仓库；② 页面技能树「自动加点」只改本地规划、没接写游戏的自动循环。详见 [KERNEL_TOOLS.md](KERNEL_TOOLS.md)。

### 常驻守卫：掉页也不停

网页自动化全靠浏览器 `setInterval`，**页面一被回收就全停**（浏览器休眠、ego lite 自升版本、标签被关）。
实测踩过：以为在挂机，实际 2 小时 49 分零连接；56 小时日志里掉页 95 次，其中 89 次间隔精确是 30 分 10 秒。

[`wog_watchdog.py`](WATCHDOG.md) 补上这一层：

```bash
python wog_watchdog.py              # 常驻：保活 + 内核合成 + SP 加点 + ego 版本哨兵
python wog_watchdog.py --selftest   # 三路连通性自检
```

四职责：20s 巡检掉页自动重拉、90s 起分组合成（无产出退避到 300s）、120s 起 SP 加点（退避到 1800s）、
600s 检查 ego lite 版本变化。实测把空转 89.5%/99.2% 的无效内核连接压掉 70%/93%。详见 [WATCHDOG.md](WATCHDOG.md)。

## 关于网页版

这个仓库也放了纯静态页面，可以直接托管。

**在线版（不用下载，浏览器直接开）：<https://wog-assistant.app.workbuddy.host/?sharecode=3BEFAVKQUD>**

> 手机 / 别的电脑上想快速看看界面、查图鉴、算伤害，用这个链接就够了。
> 要写进游戏（合成、自动入库、日常自动化）还是得在装了游戏的那台机器上用本地版。

**托管版会自己尝试连本机游戏**，多数情况下直接可用：页面用 `ws://127.0.0.1:10998` 连游戏进程，浏览器不会拦本地回环地址，只要游戏端口是开的就能读到实时数据、也能写入。

连不上只有三种原因：游戏没启动、10998 端口没开（游戏更新后常发生）、或者浏览器/扩展策略拦了本地访问。这时装「本地版」：它会在 `127.0.0.1:8791` 提供同一套页面，并负责给游戏开 10998 端口。页面里「本地版 / 连接器」那一行有下载入口和状态检测。

判断标准只有一个：右下角状态显示`已连接`就够了，显示未连接再去装本地版。
